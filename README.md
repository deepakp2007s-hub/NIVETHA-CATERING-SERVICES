# NIVETHA-CATERING-SERVICES

## 👨‍💼 NIVETHA CATERING SERVICE — ANNA OWNER APP

A professional owner management application for **Nivetha Catering Service**.

The Anna App is designed for the catering owner/admin to manage customer bookings, customers, food menus, notifications, reports, profile, and booking status from a single responsive dashboard.

---

## 📌 Project Overview

**Nivetha Catering Service — Anna App** is the owner-side application of the Nivetha Catering Service system.

The application communicates with the backend API and MongoDB database to manage catering operations.

### Main Responsibilities

- Manage customer bookings
- View booking details
- Manage customers
- Add and manage food menu items
- Update booking status
- View notifications
- View business reports
- Manage owner profile
- Manage application settings

---

# 🚀 Features

## 📊 Dashboard

The dashboard provides an overview of the catering business.

- Total bookings
- New bookings
- Confirmed bookings
- Completed bookings
- Cancelled bookings
- Customer overview
- Recent booking activity
